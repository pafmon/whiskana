# Whiskana

Una app para tomar notas de cata durante un roadtrip de whisky.

## ¿Qué es Whiskana?

Whiskana es una aplicación web diseñada para los amantes del whisky que quieren registrar sus experiencias de cata mientras viajan de destilería en destilería. Toma notas detalladas de cada dram, guarda el recuerdo de cada visita y construye tu propio diario de whisky en ruta.

## Características

- **Notas de cata** — Registra color, nariz, paladar y retrogusto de cada whisky
- **Puntuación** — Valora cada whisky con tu propia escala
- **Destilerías** — Asocia cada cata a la destilería visitada
- **Roadtrip** — Organiza tus paradas y lleva un registro cronológico del viaje
- **Galería** — Guarda fotos de las botellas y los paisajes del camino

## Cómo usar

1. Abre la app en el navegador
2. Crea un nuevo roadtrip o continúa uno existente
3. Añade una parada (destilería o tienda)
4. Registra el whisky: nombre, destilería, año, tipo
5. Completa las notas de cata: color, aromas, sabores, final
6. Guarda y comparte tu experiencia

## Notas de cata

Cada entrada incluye campos para:

| Campo | Descripción |
|---|---|
| Color | Tono e intensidad visual |
| Nariz | Aromas detectados en nariz |
| Paladar | Sabores y textura en boca |
| Retrogusto | Duración y carácter del final |
| Puntuación | Tu valoración personal (1-100) |
| Notas libres | Cualquier comentario adicional |

## Tecnología

Aplicación web estática — no requiere instalación ni conexión a internet para funcionar.
